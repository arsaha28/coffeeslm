# coffeeslm

A small GPT-2 style language model about coffee, built from scratch in PyTorch
as a learning project — one small, tested step at a time.

See [tasks.md](tasks.md) for the plan and progress.

## Quick start

```bash
python3.13 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest -v
```
